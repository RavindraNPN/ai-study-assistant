# AI Study Assistant

AI-powered study and exam assistant built using Django.

## Features

- User Registration/Login
- AI Chatbot
- Study Assistance
- PDF Study Material
- Question Explanation
- User-specific Chat History
- Study Plan Generation

## Tech Stack

- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite
- Gemini API

```bash
git clone YOUR_REPOSITORY_URL
cd ai-study-assistant
python -m venv venv
